# 🚀 FloodSnap ai

## Проблема
Кухар який тільки навчається готувати смачні страви, але він не знає рецепти, тому він витрачає багату часу на пошук рецептів.

## Рішення
Мій застосунок допомагає людям швидко отримати рецепт страви за фотографією за допомогою ші, яка аналізує зображення та генерує рецепт

## Що вміє MVP (Must Have)
- [Завантаження фото страви] Функція 1
- [Генерація рецепта за фото] Функція 2
- [Виведення готового рецепта на сторінці] Функція 3

## Що далі (Nice to Have)
- [Вибір кількості порцій]
- [Кнопка Згенерувати інший рецепт]
- [Збереження улюблених рецептів]
- [рієнтовний час приготування]

## Технології
Python, Streamlit, Html, Dotenv

## Як запустити
1. `pip install -r requirements.txt`
2. Скопіювати `.env.example` у `.env` і вставити свій API-ключ.
3. `streamlit run app.py`
